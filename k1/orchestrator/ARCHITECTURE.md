### OrchestratorService — Central Dispatch

Constructor takes all 7 operational ports + config + 5 internal services (DAGExecutor, ConstraintResolver, WorkflowEngine, ConnectorLifecycle, ErrorRouter) + ConcurrencyGuard + metrics.

**Processing flow:**

```
init()
  ├─ validate_ports → crash_recovery → MCP discovery
  ├─ subscribe_events (plan.ready, plan.failed, plan.cancelled, HIL responses)
  └─ asyncio.create_task(mailbox_loop + reap_loop)

mailbox_loop → dequeue → process(msg):
  ├─ TaskEnvelope → route_task()
  │   ├─ MEDIUM → dispatch_medium(): 1-2 fabric.execute() → aggregate
  │   └─ HIGH   → dispatch_high(): PlanRequest → Planner (fire-and-forget)
  │                                 park PendingPlanContext
  ├─ CommittedPlan → receive_plan():
  │   ├─ RACE-3 dedup (executed_plans LRU)
  │   ├─ correlate via request_id → pending_plans
  │   ├─ constraint_resolver.validate()
  │   ├─ concurrency_guard.acquire() (V1: single DAG)
  │   └─ dag_executor.execute()
  ├─ WorkflowRunRequest → dispatch_workflow()
  ├─ WorkflowSaveRequest → save_workflow()
  └─ InterruptRequest → handle_interrupt() (cooperative cancel)
```

### DAGExecutor — Adaptive Blind DAG

**`execute(CommittedPlan, SessionSnapshot) -> AggregatedResult`:**

1. `build_waves()` — Kahn's topological sort (MAX_STEPS=50, MAX_WAVES=20)
2. WAL write PLAN_START
3. For each wave:
   - Safety band re-read (abort on RED/BLACK)
   - Pre-wave guards: ConditionalEdgeEvaluator skips FALSE steps
   - ParamResolver: resolve `$step_id.result.path` references
   - Parallel dispatch (Semaphore=10) via StepRunner
   - Post-step guards: OutputSchemaGuard validates JSON Schema
   - Post-wave guards: MicroReplanCheckpoint checks discoveries, ExecutionMonitor emits progress
   - Cancel dependents of failed steps (BFS, ORCH-07)
   - WAL write WAVE_COMPLETE
4. Saga compensation in reverse declaration order
5. Aggregate results → AggregatedResult

**Constants:** `MAX_WAVES=20`, `MAX_STEPS=50`, `_MAX_CONCURRENT_PER_WAVE=10`, `_ABORT_SAFETY_LEVELS={"RED","BLACK"}`

### StepRunner — Single Step Execution

`run(step, resolved_params, prior_results, trace_id) -> StepResult`

- Builds `CapabilityRequest` from PlanStep
- Retry loop: 2 normal retries + 1 schema retry (ORCH-06)
- Output schema validation via `jsonschema.validate()` (Draft 2020-12)
- Schema hint injection into params on retry

### ConstraintResolver — Pre-Execution Validation

`validate(CommittedPlan) -> ValidationResult`

- 3-cycle state machine: alternatives → re-check → HIL fallback
- Registry queries via `IFabricGatewayPort.query_registry()`
- Alternative scoring: 0.6 schema_overlap + 0.2 safety_band + 0.2 name_similarity
- HIL fallback via `IDeltaEmitPort.emit_hil_request()`

### Details

**1. Fabric→Orch** — `FabricGatewayAdapter` (259 lines) wraps `k1.fabric.fabric.Fabric`. Pure pass-through. `FabricError` → `AdapterError(DEGRADED)`. No CB owned (CB_FABRIC on Concierge per PROTOCOL-4).

**2. Planner→Orch** — `PlannerAdapter` (199 lines) defines structural protocol `IPlannerMailbox`. Owns `CB_PLANNER` (from `k1.fabric.circuit_breaker`). Two-phase: `request_plan()` fire-and-forget → Planner publishes `k1.planner.plan.ready.v1` → OrchestratorService event handler → mailbox. `micro_replan()` synchronous 10s timeout.

**3. SS→Orch** — `StateReadAdapter` (132 lines) wraps `ISessionStateReader` from `k1.fabric.ports.state_reader`. READ-ONLY enforced (ORCH-01). Lock-free copy-on-write snapshots.

**4. Bridge→Orch** — `BridgeWriteAdapter` (190 lines) defines `IBridgeClient` protocol for K0 connector. Fire-and-forget writes (WAL entries, audit). Read failures raise `DEGRADED` (blocks crash recovery). Edge-First: continues if K0 offline.

**5a. Bus:Mailbox** — `MailboxAdapter` (192 lines) in-memory MPSC + WFQ (REALTIME 60%, INTERACTIVE 30%, BACKGROUND 10%). Thread-safe via `threading.Lock`. Max depth=100. `MailboxFullError` on overflow.

**5b. Bus:Event** — `EventSubscriptionAdapter` (121 lines) wraps `k1.fabric.ports.event_port.IEventPort`. Tracks handles for shutdown bulk-unsubscribe. Wildcard topic matching (fnmatch).

**5c. Bus:Delta** — `DeltaEmitAdapter` (123 lines) dual-publishes: `k1.hil.*` and `k1.orchestration.*` topics go to BOTH `IEventPort` + `IDeltaBusPort`. All others event-only. ORCH-09: injects trace_id.

**6. Concierge→Orch** — Concierge creates `TaskEnvelope` from POC-local types in `k1.concierge.orchestrator.types` (explicitly NOT from `k1.orchestrator.types`). Fields are structurally INCOMPATIBLE (POC uses task_id/budget/session_id/ComplexityTier enum; production uses envelope_id/timeout_ms/caller_id/tier as str). Translation adapter `_FabricGatewayAdapter` in `k1/concierge/kernel/bootstrap.py` bridges POC→production at dispatch boundary. ✅ Verified E-0.5.5.

**7. Orch→Planner** — All types (`PlanRequest`, `CommittedPlan`, `PlanAck`, `MicroReplanRequest`) defined locally in `k1.orchestrator.types`. Planner satisfies `IPlannerMailbox` protocol via structural typing. Correlation via `request_id` field.

### What's Working Well

- **Cleanest hexagonal architecture of all K1 components scanned so far.** All 9 adapters import only from `k1.fabric` (shared infrastructure) and `k1.orchestrator` (local). Zero imports from peer components (concierge, model_hub, planner, sessionstate, memory_writer).
- **Most comprehensive test suite.** ~1,800 test functions covering every service, guard, invariant, lifecycle stage, and chaos scenario.
- **Two-phase HIGH tier protocol.** Fire-and-forget PlanRequest + event-driven CommittedPlan arrival with RACE-3 dedup and stale context reaping — production-ready pattern.
- **Guard pipeline extensible.** `DAGGuard` ABC with `before_wave`/`after_step`/`after_wave` hooks. New guards plug in via config list ordering.
- **Factory composition root.** 15-step `OrchestratorFactory` cleanly separates wiring from business logic. `create_for_testing()` enables test isolation.
