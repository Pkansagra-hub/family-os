## Context

P03 Consolidation executes as a 9-phase pipeline (R0-R8). Each phase must be:
- **Atomic:** Complete or rollback entirely
- **Idempotent:** Safe to retry without side effects
- **Retriable:** Independent recovery without reprocessing prior phases

---

## Decision

Adopt [Dossier Appendix G](../../../pipelines/P03_consolidation_dossier_v2.md#appendix-g-r0-r8-state-machine-specification) as the **normative specification** for P03 phase execution.

### State Machine Overview

```
R0 (INIT) → R1 (SCORE) → R2 (CLUST) → R3 (PRUNE) → R4 (KG) → R5 (DREAM) → R6 (STAGE) → R7 (WRITE) → R8 (EMIT)

States per phase: [INIT] [PROC] [SKIP] [DONE] [FAIL]
```

### Phase Specifications

| Phase | Purpose | Timeout | Idempotency Key | Retryable | Skip Condition |
|-------|---------|---------|-----------------|-----------|----------------|
| R0 | Batch Selection | 30s | `p03:cycle:{cycle_ulid}` | Yes | Never |
| R1 | Importance Scoring | 60s | `p03:r1:{cycle_ulid}:{batch_hash}` | Yes | Never |
| R2 | Episodic Clustering | 120s | `p03:r2:{cycle_ulid}:{batch_hash}` | Yes | batch_size < 2 |
| R3 | Forgetting/Pruning | 60s | `p03:r3:{cycle_ulid}:{batch_hash}` | Yes | Never |
| R4 | KG Building | 90s | `p03:r4:{cycle_ulid}:{batch_hash}` | Yes | Never |
| R5 | Dream Exploration | 120s | `p03:r5:{cycle_ulid}:{batch_hash}` | Yes | Config disabled |
| R6 | Staging Updates | 30s | `p03:r6:{cycle_ulid}:{batch_hash}` | Yes | Never |
| R7 | Truth Writes | 120s | `p03:r7:{cycle_ulid}:{batch_hash}` | Yes | Never |
| R8 | Event Emission | 30s | `p03:r8:{cycle_ulid}:{batch_hash}` | Yes | Never |

### Idempotency Key Pattern

```
p03:{phase}:{cycle_ulid}:{batch_hash}

- phase: r0-r8
- cycle_ulid: ULID generated at R0
- batch_hash: SHA256(sorted(event_ids))[:16]
```

### Retry Matrix

| Phase | Max Retries | Backoff | DLQ Action |
|-------|-------------|---------|------------|
| R0 | 3 | Exponential | Manual intervention |
| R1 | 3 | Exponential | Skip batch |
| R2 | 2 | Linear | Micro-episode fallback |
| R3 | 0 | N/A | Never fails |
| R4 | 3 | Exponential | Defer KG |
| R5 | 1 | Fixed | Skip dream |
| R6-R8 | 3 | Exponential | Critical alert |

---

## Consequences

### Positive
- Each phase independently testable and recoverable
- Idempotency enables safe retry
- Clear timeout budgets prevent runaway processes

### Negative
- Idempotency ledger storage overhead
- Complex retry logic
