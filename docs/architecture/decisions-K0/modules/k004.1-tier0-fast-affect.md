# K004.1: Tier-0 Fast Affect

**Status**: PROPOSED | **Parent**: [K004](k004-affect-service.md)

## Current Implementation

- Lightweight sentiment model (distilled transformer)
- Lexicon-based fallback for < 10 words
- Batch processing support (16 events)
- Pure Python with optional GPU acceleration

## Future Capabilities

- ONNX runtime for cross-platform optimization
- Quantized models (INT8) for edge deployment
- Caching for repeated phrases
- A/B testing framework for model updates

## Performance: P95 ≤70ms, P99 ≤100ms
