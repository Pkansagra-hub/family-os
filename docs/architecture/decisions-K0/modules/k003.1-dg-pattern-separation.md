# K003.1: DG Pattern Separation

**Status**: PROPOSED | **Parent**: [K003](k003-hippocampus-architecture.md)

## Context

DGService (M01) must generate perceptual fingerprints <15ms P95 for P02 write-path.

## Current Implementation

- 64-bit SimHash from text + participants + place + time
- MinHash32 signature (32 permutations)
- Pure Python implementation

## Future Capabilities

- Adaptive MinHash (16-128 permutations based on content length)
- LSH indexing for fast neighbor queries
- Multi-modal fingerprinting (image perceptual hashing, audio fingerprints)
- Hardware acceleration (SIMD, GPU for batch operations)

## Performance Budget

- P95: ≤15ms
- P99: ≤25ms
- Memory: <10MB per operation

## References

- Charikar (2002) - Similarity estimation techniques from rounding algorithms
- Broder (1997) - On the resemblance and containment of documents
