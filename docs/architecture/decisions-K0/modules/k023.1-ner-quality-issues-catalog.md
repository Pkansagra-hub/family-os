# NER Quality Issues Catalog

**Related ADR**: K023 - Entity Filtering Consolidation
**Date**: 2025-01-19
**Status**: ACTIVE (issues being mitigated via filtering)

---

## Executive Summary

UltraBERT v3.0.4 NER heads produce significant garbage entities that require extensive post-processing filtering. This document catalogs all known issues by NER head.

**Root Cause**: NER models are trained on news/Wikipedia corpora, not personal family narratives. They lack context for:

- Conversational writing style
- Family-specific terminology
- Emotional language
- Daily routine descriptions

---

## NER_FAMILY Head Issues

The `ner_family` head is trained for family context but has significant false positive rates for certain labels.

### Issue NF-001: MILESTONE Tags Verbs

**Problem**: MILESTONE label applied to past-tense verbs instead of actual life events.

| Input Text | Tagged Entity | Expected | Problem |
|------------|---------------|----------|---------|
| "Emma learned to ride a bike" | "learned" | SKIP | Verb, not milestone |
| "Sofia passed her driving test" | "passed" | SKIP | Verb, not milestone |
| "I finally got promoted" | "promoted" | SKIP | Verb, not milestone |
| "She accepted the job offer" | "accepted" | SKIP | Verb, not milestone |

**Mitigation**: Keyword validation - require milestone_keywords (graduation, wedding, birthday, etc.)

---

### Issue NF-002: FAMILY_EVENT Tags Pronouns and Verbs

**Problem**: FAMILY_EVENT label applied to possessives, numbers, and action verbs.

| Input Text | Tagged Entity | Expected | Problem |
|------------|---------------|----------|---------|
| "Our trip to the lake" | "our" | SKIP | Possessive pronoun |
| "We celebrated for 3 hours" | "3" | SKIP | Number, not event |
| "They attended the ceremony" | "attended" | SKIP | Verb, not event |

**Mitigation**: Garbage word filter + short entity filter

---

### Issue NF-003: HEIRLOOM Tags Prepositions and Adjectives

**Problem**: HEIRLOOM label applied to common words instead of physical objects.

| Input Text | Tagged Entity | Expected | Problem |
|------------|---------------|----------|---------|
| "Grandma's old ring" | "old" | SKIP | Adjective |
| "Passed down to me" | "to" | SKIP | Preposition |
| "The watch from 1942" | "from" | SKIP | Preposition |
| "It was in the attic" | "in" | SKIP | Preposition |

**Mitigation**: Heirloom keyword validation (ring, watch, jewelry, photo, etc.)

---

### Issue NF-004: PET Tags Determiners

**Problem**: PET label applied to articles when pet name follows.

| Input Text | Tagged Entity | Expected | Problem |
|------------|---------------|----------|---------|
| "Fur the cat" | "the" | SKIP | Determiner |
| "Buddy the dog" | "the" | SKIP | Determiner |

**Mitigation**: Garbage word filter (the, a, an)

---

### Issue NF-005: PERSON Overlap with ner_general

**Problem**: ner_family PERSON entities often duplicate ner_general PERSON with lower quality.

| Source | Entity | Confidence | Issue |
|--------|--------|------------|-------|
| ner_family | "Emma" | 0.82 | Correct but overlaps |
| ner_general | "Emma" | 0.94 | Higher confidence |

**Mitigation**:

- Previously: REJECTED_NER_FAMILY included PERSON
- Now: Confidence-based filtering (UltraBERT 3.0.4) handles this

---

## NER_GENERAL Head Issues

The `ner_general` head uses standard NER (PERSON, ORG, LOC) but produces garbage on informal text.

### Issue NG-001: PERSON Tags Common Verbs

**Problem**: PERSON label applied to past-tense verbs (capitalized at sentence start).

| Input Text | Tagged Entity | Label | Problem |
|------------|---------------|-------|---------|
| "Met with John today" | "Met" | PERSON | Verb mistagged |
| "Asked about the project" | "Asked" | PERSON | Verb mistagged |
| "Called the team" | "Called" | PERSON | Verb mistagged |
| "Thinking about vacation" | "Thinking" | PERSON | Verb mistagged |

**Mitigation**: Lowercase single-word filter (rejects words starting lowercase in original)

---

### Issue NG-002: PERSON Tags Emotions/Adjectives

**Problem**: Emotion words and adjectives tagged as PERSON.

| Input Text | Tagged Entity | Label | Problem |
|------------|---------------|-------|---------|
| "Feeling anxious today" | "anxious" | PERSON | Adjective |
| "So grateful for help" | "grateful" | PERSON | Adjective |
| "Really stressed about work" | "stressed" | PERSON | Adjective |
| "Excited about the trip" | "Excited" | PERSON | Adjective |

**Mitigation**: Garbage word filter (anxious, grateful, stressed, excited, etc.)

---

### Issue NG-003: ORG Tags Common Nouns

**Problem**: ORG label applied to everyday nouns.

| Input Text | Tagged Entity | Label | Problem |
|------------|---------------|-------|---------|
| "Had a meeting about Q2" | "meeting" | ORG | Common noun |
| "Checked my email" | "email" | ORG | Common noun |
| "The afternoon was busy" | "afternoon" | ORG | Time word |
| "Coffee with manager" | "manager" | ORG | Role, not org |

**Mitigation**: Garbage word filter (meeting, email, afternoon, manager, etc.)

---

### Issue NG-004: Partial Entity Extraction

**Problem**: Sub-word fragments extracted instead of full entity.

| Source Text | Tagged Entity | Expected | Problem |
|-------------|---------------|----------|---------|
| "Lincoln School" | "Lincoln" | "Lincoln School" | Partial extraction |
| "San Francisco" | "San" | "San Francisco" | Partial extraction |
| "Bella Notte restaurant" | "Bella" | "Bella Notte" | Partial extraction |

**Mitigation**:

- Word boundary validation (is_complete_word)
- Span overlap deduplication (family spans take priority)

---

### Issue NG-005: Time Fragments

**Problem**: Time expressions tagged as entities.

| Input Text | Tagged Entity | Label | Problem |
|------------|---------------|-------|---------|
| "Meeting at 3pm" | "3pm" | PERSON | Time fragment |
| "Call at 10am" | "10am" | PERSON | Time fragment |
| "Lunch at 12pm" | "12pm" | PERSON | Time fragment |

**Mitigation**: Time fragment regex filter (^\d{1,2}(?:am|pm|AM|PM)$)

---

### Issue NG-006: Verb-Form Words

**Problem**: Words ending in -ed, -ing tagged as entities.

| Input Text | Tagged Entity | Label | Problem |
|------------|---------------|-------|---------|
| "Learned a lot" | "Learned" | PERSON | Verb |
| "Working on project" | "Working" | ORG | Verb |
| "Organized the files" | "Organized" | PERSON | Verb |

**Mitigation**: Verb suffix regex filter (^[a-z]+(?:ed|ing|ized|ised)$)

---

### Issue NG-007: ORG vs LOCATION Confusion

**Problem**: Physical locations tagged as ORG instead of LOC.

| Input Text | Tagged Entity | Actual Label | Expected |
|-------------|---------------|--------------|----------|
| "Lincoln School" | "Lincoln School" | ORG | LOCATION |
| "City Sports Complex" | "City Sports Complex" | ORG | LOCATION |
| "Central Park" | "Central Park" | ORG | LOCATION |

**Mitigation**: Location affordance reclassification (school, park, center, etc. -> LOCATION)

---

## Confidence Threshold Issues

### Issue CT-001: Low Confidence Garbage (Pre-v3.0.4)

**Problem**: UltraBERT v3.0.3 used argmax without confidence threshold, accepting any prediction.

| Entity | Confidence | Accepted? | Problem |
|--------|------------|-----------|---------|
| "afternoon" | 0.31 | Yes | Below threshold |
| "asked" | 0.28 | Yes | Below threshold |
| "meeting" | 0.42 | Yes | Below threshold |

**Fix Applied**: UltraBERT v3.0.4 adds `min_entity_confidence=0.5` in `_postprocess_token_classification`

## Filter Pipeline Summary

All issues are mitigated by the consolidated filter pipeline in `entity_extractor.filter_and_normalize()`:

```
Raw NER Entities
     │
     ▼
┌─────────────────────────────────────┐
│ 1. Confidence threshold (0.5)       │ ← CT-001
│ 2. Text normalization               │
│ 3. Short entity filter (< 2 chars)  │ ← NF-002
│ 4. Garbage word filter (~150 words) │ ← NG-001, NG-002, NG-003, NF-003, NF-004
│ 5. Lowercase single-word filter     │ ← NG-001
│ 6. Time fragment filter             │ ← NG-005
│ 7. Verb suffix filter               │ ← NG-006
│ 8. Word boundary validation         │ ← NG-004
│ 9. ORG->LOCATION reclassification   │ ← NG-007
│ 10. NER family keyword validation   │ ← NF-001, NF-003
└─────────────────────────────────────┘
     │
     ▼
Clean Entities for KG
```
