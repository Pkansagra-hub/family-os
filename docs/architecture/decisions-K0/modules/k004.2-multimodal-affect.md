# k004.2 - Multi-Modal Affect Classification (Future Extension)

**Status**: PROPOSED | **Parent**: [k004 - Affect Service Architecture](k004-affect-service.md)

---

## Executive Summary

**Multi-Modal Affect** extends the text-only k004.1 (Tier-0) and Tier-1 classification to incorporate **visual**, **audio**, and **biometric** signals for richer emotional context. This is a **future extension** not part of P02 Phase 1, but documented here for architectural planning.

**Key Design Points**:

1. **Facial Expression Analysis**: Detect emotions from images/video (Ekman's basic emotions: joy, sadness, anger, fear, surprise, disgust)
2. **Voice Tone Analysis**: Analyze speech prosody (pitch, tempo, energy) for emotional arousal
3. **Late Fusion Architecture**: Combine text, image, audio, biometric modalities using weighted averaging or attention mechanisms
4. **Cross-Modal Consistency**: Flag discrepancies (e.g., text="happy" but facial expression="sad" → possible sarcasm or masking)
5. **Deferred to P08**: Multimodal processing deferred to background pipeline (P08) due to high latency (200-500ms per modality)

**Performance Budget** (future): P95 ≤500ms (acceptable for P08 background processing, not P02 write path).

---

## Context

### Why Multimodal Affect?

Text-only affect classification (k004.1) misses important emotional cues:

1. **Facial Expressions**: Microexpressions reveal suppressed emotions (e.g., smiling while stressed)
2. **Voice Tone**: Prosody conveys arousal (e.g., excited voice vs. monotone)
3. **Biometrics**: Heart rate, skin conductance indicate physiological arousal
4. **Context Discrepancies**: Text-image mismatches flag deception or complex emotions

**Use Cases**:

- **Therapy Applications (P06)**: Therapists need rich emotional context (facial expressions + text)
- **Journaling Insights**: "Your mood was lower than your words suggested" (detect emotional masking)
- **Family Communication**: Detect when child's "I'm fine" contradicts facial expression (intervention trigger)

### Why Not in P02 (Write Path)?

Multimodal affect processing is **too slow** for P02:

| Modality | Latency | GPU Required |
|----------|---------|--------------|
| Text (Tier-0) | <2ms | No |
| Text (Tier-1) | <60ms | Yes |
| **Image (facial expression)** | **200-300ms** | **Yes** |
| **Audio (voice tone)** | **150-250ms** | **Yes** |
| **Biometric (optional)** | **50-100ms** | **No** |
| **Cross-modal fusion** | **+50ms** | **Yes** |
| **Total (all modalities)** | **≥500ms** | **Yes** |

P02 write path budget is <100ms total. **500ms multimodal affect blocks ingestion**.

**Solution**: Defer multimodal affect to **P08 background pipeline**:

- P02 writes text-only affect (fast, <70ms)
- P08 processes images/audio asynchronously (500ms acceptable in background)
- Multimodal affect back-propagated to `st_hipp_events` (eventual consistency)

### Biological Inspiration: Multimodal Emotion Integration

The brain integrates emotion signals from multiple modalities:

- **Visual Cortex**: Processes facial expressions, body language
- **Auditory Cortex**: Processes voice tone, prosody
- **Somatosensory Cortex**: Processes touch, physiological arousal
- **Amygdala**: Integrates all signals for unified emotional response

Our **late fusion architecture** mimics this multi-sensory integration:

- Each modality processed independently (unimodal affect scores)
- Fusion layer combines scores with learned weights (attention mechanism)
- Final output: unified valence/arousal with confidence scores per modality

## Decision

### Multi-Modal Architecture Overview

```
Input Event (with attachments):
  - text: "Had a great day!"
  - image: family_photo.jpg (facial expressions)
  - audio: voice_note.mp3 (speech prosody)
  - biometric: heart_rate=78 bpm (optional)

↓

[Unimodal Affect Models] (parallel processing)
  ├─ Text Model (k004.1 Tier-0/Tier-1) → valence_text=0.85, arousal_text=0.6
  ├─ Image Model (Facial Expression CNN) → valence_image=0.75, arousal_image=0.5
  ├─ Audio Model (Speech Prosody RNN) → valence_audio=0.80, arousal_audio=0.7
  └─ Biometric Model (Arousal Estimator) → arousal_biometric=0.65

↓

[Late Fusion Layer] (attention-weighted averaging)
  - Compute modality confidence scores (based on data quality)
  - Weighted fusion: valence_final = Σ(weight_i × valence_i)
  - Flag cross-modal discrepancies (text-image mismatch)

↓

Output: MultimodalAffectAnnotation
  - valence_final: 0.80
  - arousal_final: 0.65
  - dominant_emotions: ["joy", "excitement"]
  - modality_contributions: {text: 0.4, image: 0.3, audio: 0.2, biometric: 0.1}
  - cross_modal_consistency: 0.85 (high = consistent, low = discrepancy)
```

### Modality 1: Facial Expression Analysis

**Algorithm**: Convolutional Neural Network (CNN) trained on facial expression datasets (FER2013, AffectNet)

**Input**: Image (RGB, 224×224 pixels)
**Output**: Ekman's 6 basic emotions + neutral (7 classes)

```python
def analyze_facial_expression(image: np.ndarray) -> FacialAffectAnnotation:
    """
    Detect facial expressions using pre-trained CNN.
    Returns emotion probabilities + valence/arousal mapping.
    """
    # Preprocess image (face detection + alignment)
    faces = face_detector.detect(image)  # OpenFace or dlib
    if not faces:
        return None  # No face detected

    face_crop = faces[0].aligned_crop(size=(224, 224))

    # CNN inference (ResNet-50 backbone)
    emotion_logits = facial_emotion_model(face_crop)
    emotion_probs = softmax(emotion_logits)  # [joy, sadness, anger, fear, surprise, disgust, neutral]

    # Map Ekman emotions to valence/arousal
    valence = (
        emotion_probs['joy'] * 1.0 +
        emotion_probs['surprise'] * 0.5 +
        emotion_probs['neutral'] * 0.5 +
        emotion_probs['sadness'] * 0.0 +
        emotion_probs['anger'] * 0.0 +
        emotion_probs['fear'] * 0.2 +
        emotion_probs['disgust'] * 0.1
    )

    arousal = (
        emotion_probs['joy'] * 0.7 +
        emotion_probs['anger'] * 0.9 +
        emotion_probs['fear'] * 0.8 +
        emotion_probs['surprise'] * 0.8 +
        emotion_probs['sadness'] * 0.3 +
        emotion_probs['disgust'] * 0.5 +
        emotion_probs['neutral'] * 0.2
    )

    return FacialAffectAnnotation(
        valence=valence,
        arousal=arousal,
        dominant_emotion=max(emotion_probs, key=emotion_probs.get),
        emotion_probs=emotion_probs,
        confidence=max(emotion_probs.values())  # Highest probability = confidence
    )
```

**Performance**:

- **Latency**: 200-300ms (GPU), 1-2 seconds (CPU)
- **Accuracy**: 70-75% on wild datasets (lower than lab conditions due to lighting, angle, occlusion)
- **Coverage**: ~60% of events with images (not all events have photos)

**Limitations**:

- Cultural differences in expression (e.g., Japanese suppress negative emotions more than Americans)
- Microexpressions (fleeting, <200ms) hard to detect from still images (need video)
- Occlusion (masks, glasses, hair) reduces accuracy

### Modality 2: Voice Tone Analysis (Speech Prosody)

**Algorithm**: Recurrent Neural Network (RNN) trained on speech prosody features (pitch, energy, tempo)

**Input**: Audio (WAV, 16kHz sample rate)
**Output**: Valence/arousal scores from prosody

```python
def analyze_voice_tone(audio: np.ndarray, sample_rate: int) -> VoiceAffectAnnotation:
    """
    Extract prosody features and predict affect from voice tone.
    Returns valence/arousal without transcribing speech content.
    """
    # Extract prosody features (librosa library)
    pitch_contour = librosa.yin(audio, fmin=50, fmax=400)  # Fundamental frequency
    energy = librosa.feature.rms(audio)  # Energy (loudness)
    tempo = librosa.beat.tempo(audio)  # Speaking rate

    # Statistical aggregations
    pitch_mean = np.mean(pitch_contour)
    pitch_std = np.std(pitch_contour)
    energy_mean = np.mean(energy)

    # Feature vector
    features = np.array([pitch_mean, pitch_std, energy_mean, tempo])

    # RNN inference (trained on emotional speech datasets: RAVDESS, IEMOCAP)
    valence, arousal = voice_affect_model.predict(features)

    return VoiceAffectAnnotation(
        valence=valence,
        arousal=arousal,
        pitch_mean=pitch_mean,
        energy_mean=energy_mean,
        tempo=tempo[0],
        confidence=0.7  # Lower confidence than text (prosody less reliable)
    )
```

**Performance**:

- **Latency**: 150-250ms (depends on audio length)
- **Accuracy**: 60-65% (prosody alone less reliable than text+prosody combined)
- **Coverage**: ~30% of events with audio (voice notes, video attachments)

**Limitations**:

- Language-dependent (prosody patterns vary across languages)
- Background noise degrades accuracy
- Monotone speakers (e.g., flat affect) hard to classify

### Modality 3: Biometric Signals (Optional)

**Algorithm**: Simple arousal estimation from heart rate, skin conductance (if available from wearables)

**Input**: Heart rate (BPM), skin conductance (μS)
**Output**: Arousal score only (biometrics don't indicate valence)

```python
def analyze_biometric(heart_rate: int, skin_conductance: float) -> BiometricAffectAnnotation:
    """
    Estimate arousal from physiological signals.
    Valence cannot be determined from biometrics alone.
    """
    # Normalize heart rate to arousal scale (60-100 BPM → 0.0-1.0 arousal)
    arousal_hr = (heart_rate - 60) / 40  # 60 BPM = 0.0, 100 BPM = 1.0
    arousal_hr = np.clip(arousal_hr, 0.0, 1.0)

    # Normalize skin conductance (0-20 μS → 0.0-1.0 arousal)
    arousal_sc = skin_conductance / 20
    arousal_sc = np.clip(arousal_sc, 0.0, 1.0)

    # Average arousal
    arousal = (arousal_hr + arousal_sc) / 2

    return BiometricAffectAnnotation(
        arousal=arousal,
        valence=None,  # Cannot determine valence from biometrics
        heart_rate=heart_rate,
        skin_conductance=skin_conductance,
        confidence=0.5  # Lower confidence (physiological arousal ≠ emotional arousal)
    )
```

**Performance**:

- **Latency**: <50ms (simple computation)
- **Accuracy**: Arousal only (60-70% correlation with emotional arousal)
- **Coverage**: <5% of events (requires wearable integration)

**Limitations**:

- Arousal ≠ emotion (high arousal could be joy or fear)
- Physical activity confounds emotional arousal (running → high HR but not emotional)
- Low adoption (most users don't wear biometric sensors)

### Late Fusion: Combining Modalities

**Algorithm**: Attention-weighted averaging (learns optimal weights per modality)

```python
def fuse_multimodal_affect(
    text_affect: Optional[AffectAnnotation],
    image_affect: Optional[FacialAffectAnnotation],
    audio_affect: Optional[VoiceAffectAnnotation],
    biometric_affect: Optional[BiometricAffectAnnotation]
) -> MultimodalAffectAnnotation:
    """
    Combine unimodal affect scores using learned attention weights.
    Handles missing modalities gracefully (not all events have images/audio).
    """
    valence_scores = []
    arousal_scores = []
    weights = []
    modality_contributions = {}

    # Text modality (always available)
    if text_affect:
        valence_scores.append(text_affect.valence)
        arousal_scores.append(text_affect.arousal)
        weights.append(0.5)  # Text weight = 50% (most reliable)
        modality_contributions['text'] = 0.5

    # Image modality (if available)
    if image_affect:
        valence_scores.append(image_affect.valence)
        arousal_scores.append(image_affect.arousal)
        weight = 0.3 * image_affect.confidence  # Reduce weight if low confidence
        weights.append(weight)
        modality_contributions['image'] = weight

    # Audio modality (if available)
    if audio_affect:
        valence_scores.append(audio_affect.valence)
        arousal_scores.append(audio_affect.arousal)
        weight = 0.2 * audio_affect.confidence
        weights.append(weight)
        modality_contributions['audio'] = weight

    # Biometric modality (arousal only)
    if biometric_affect:
        arousal_scores.append(biometric_affect.arousal)
        weight = 0.1 * biometric_affect.confidence
        weights.append(weight)
        modality_contributions['biometric'] = weight

    # Normalize weights
    weights = np.array(weights) / sum(weights)

    # Weighted average
    valence_final = np.average(valence_scores, weights=weights[:len(valence_scores)])
    arousal_final = np.average(arousal_scores, weights=weights)

    # Cross-modal consistency check
    consistency = compute_cross_modal_consistency(valence_scores, arousal_scores)

    return MultimodalAffectAnnotation(
        valence=valence_final,
        arousal=arousal_final,
        dominant_emotions=map_circumplex_to_emotions(valence_final, arousal_final),
        modality_contributions=modality_contributions,
        cross_modal_consistency=consistency,  # 0.0-1.0 (high = consistent)
        model_version="multimodal_fusion_v1.0"
    )
```

**Cross-Modal Consistency**:

```python
def compute_cross_modal_consistency(valence_scores: List[float], arousal_scores: List[float]) -> float:
    """
    Measure consistency across modalities.
    High consistency = modalities agree (e.g., text and face both positive).
    Low consistency = modalities conflict (e.g., text positive, face sad) → flag for review.
    """
    if len(valence_scores) < 2:
        return 1.0  # Only one modality, trivially consistent

    # Compute pairwise differences
    valence_std = np.std(valence_scores)  # Low std = high consistency
    arousal_std = np.std(arousal_scores)

    # Consistency score (inverse of variance, normalized)
    consistency_valence = max(0.0, 1.0 - valence_std)
    consistency_arousal = max(0.0, 1.0 - arousal_std)

    return (consistency_valence + consistency_arousal) / 2
```

**Use Case**: Low consistency (<0.6) flags possible emotional masking (e.g., text="I'm fine" but face="sad").

## Alternatives Considered

### Alternative 1: Early Fusion (Feature-Level) (Rejected)

**Approach**: Concatenate features from all modalities into single vector, train unified model.

**Pros**:
- Can learn cross-modal correlations (e.g., pitch + facial expression)
- Single model (simpler architecture)

**Cons**:
- ❌ **Missing modality problem**: Model fails if any modality missing (cannot handle text-only events)
- ❌ **Training complexity**: Requires multimodal training dataset (rare, expensive to collect)
- ❌ **Less modular**: Cannot swap individual modality models

**Rejection Rationale**: Most events have text-only (no images/audio). Early fusion cannot handle missing modalities gracefully.

### Alternative 2: Hierarchical Fusion (Rejected)

**Approach**: Fuse text+audio first, then combine with image, then biometric (sequential fusion).

**Pros**:
- Captures pairwise interactions (e.g., text-audio consistency before adding image)

**Cons**:
- ❌ **Order-dependent**: Fusion order affects results
- ❌ **Complexity**: More hyperparameters to tune (fusion thresholds at each level)
- ❌ **No clear hierarchy**: No evidence that text-audio should fuse before image

**Rejection Rationale**: Late fusion (parallel) simpler and equally effective. No clear advantage to hierarchical fusion.

### Alternative 3: Immediate Fusion in P02 (Rejected)

**Approach**: Process all modalities in P02 write path (not deferred to P08).

**Pros**:
- Multimodal affect available immediately (no eventual consistency delay)

**Cons**:
- ❌ **Latency**: 500ms multimodal processing blocks P02 write path (<100ms budget)
- ❌ **Scalability**: GPU inference limits throughput (10-20 events/sec per GPU)

**Rejection Rationale**: Cannot meet P02 latency budget. Must defer to P08 background processing.

## Consequences

### Positive Consequences

✅ **Richer Emotional Context (Facial + Voice + Biometric)**
- Detects emotional masking (text="fine" but face="sad")
- Supports therapy applications (therapists need visual cues)

✅ **Late Fusion Handles Missing Modalities Gracefully**
- Works with text-only, text+image, text+audio, or all modalities
- No training complexity (unimodal models independent)

✅ **Deferred to P08 (No Write-Path Blocking)**
- P02 remains fast (<100ms) with text-only affect
- Multimodal affect back-propagated asynchronously (eventual consistency acceptable)

✅ **Cross-Modal Consistency Flags Deception/Masking**
- Low consistency (<0.6) triggers review (possible emotional suppression)
- Useful for therapy and child wellbeing monitoring

### Negative Consequences (with Mitigations)

⚠️ **High Latency (500ms) Limits to Background Processing**
- **Issue**: Cannot use in real-time applications (e.g., chatbot responses)
- **Mitigation**: Defer to P08 (background pipeline); acceptable for therapy review, journaling insights

⚠️ **Low Coverage (30-60% of Events Have Images/Audio)**
- **Issue**: Most events text-only (no multimodal enrichment)
- **Mitigation**: Text-only affect (k004.1) sufficient for most events; multimodal adds value when available

⚠️ **Accuracy Lower Than Text (70% facial, 60% voice)**
- **Issue**: Image/audio less reliable than text for emotion classification
- **Mitigation**: Weight text higher in fusion (50% weight); use image/audio as supplementary signals

⚠️ **Cultural and Contextual Biases**
- **Issue**: Facial expression norms vary by culture (e.g., Asian vs. Western)
- **Mitigation**: Future work: culture-adaptive models; user feedback loop to calibrate
