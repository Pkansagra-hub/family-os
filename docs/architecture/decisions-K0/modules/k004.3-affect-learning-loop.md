# K004.3: Affect Learning Loop

**Status**: PROPOSED | **Parent**: [K004](k004-affect-service.md)

## Future Capabilities

- User feedback collection (correct/incorrect affect)
- Personalized baselines (learn per-user affect norms)
- Cultural adaptation (adjust for cultural affect expression)
- Temporal patterns (detect mood shifts over weeks/months)
- Fine-tuning on user-specific data (federated learning)

## Privacy Considerations

- Affect models must respect retention policies
- No cross-tenant training data leakage
- Opt-in for personalization
