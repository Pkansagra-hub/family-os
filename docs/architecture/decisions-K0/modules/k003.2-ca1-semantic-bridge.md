# K003.2: CA1 Semantic Bridge

**Status**: PROPOSED | **Parent**: [K003](k003-hippocampus-architecture.md)

## Context

CA1Bridge (M02) extracts semantic structure for knowledge graph construction.

## Current Implementation

- External HTTP service for entity extraction
- NER (Named Entity Recognition) for people, places, activities
- Simple subject-predicate-object triple generation
- Circuit breaker with 40ms timeout

## Future Capabilities

- Multi-hop reasoning over knowledge graph
- Temporal entity resolution (track person identity over time)
- Cross-document entity linking and coreference
- Semantic role labeling (agent, patient, instrument)
- Event causality detection
- Multi-lingual entity extraction

## Performance Budget

- P95: ≤40ms
- P99: ≤60ms
- Memory: <50MB per operation
- Availability: 99.5% (external service)

## References

- Linguistic Data Consortium - PropBank and FrameNet
- ACE 2005 - Automatic Content Extraction standards
