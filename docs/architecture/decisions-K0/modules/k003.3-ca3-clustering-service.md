# K003.3: CA3 Clustering Service

**Status**: PROPOSED | **Parent**: [K003](k003-hippocampus-architecture.md)

## Context

CA3Service (M03) finds near-duplicates and clusters similar episodes (used by P03).

## Current Implementation

- Hamming distance queries on SimHash (<4 bits difference)
- Jaccard similarity on MinHash (>0.8 threshold)
- Simple greedy clustering
- Batch processing in P03 background pipeline

## Future Capabilities

- Incremental clustering (update on new events without full recomputation)
- Hierarchical clustering (detect sub-episodes within larger events)
- Novelty scoring (quantify deviation from known patterns)
- Temporal decay (older memories less influential)
- LSH indexing for O(1) neighbor queries instead of O(n)
- Density-based clustering (DBSCAN) for arbitrary cluster shapes

## Performance Budget

- No strict latency (background processing)
- Throughput: 10K events/day per tenant
- Memory: <500MB for clustering state

## References

- Ester et al (1996) - DBSCAN: A density-based algorithm
- Rousseeuw (1987) - Silhouettes: A graphical aid to clustering
