# ADR 0078: Tool Call Batching Pipeline (M4 Epic 1)

**Status**: Proposed
**Last Updated**: 2025-01-15
**Milestone**: M4 - Tool Call Optimization & Streaming
**Epic**: 4.1 - Tool Call Batching Pipeline
**Related ADRs**: 0022 (K0 Bridge Bounded Batching), 0061 (Backpressure Cascade), 0015 (WebSocket Binary Protocol), 0033a-b (MCP Sandbox), 0024a (Performance Budgets)

---

## 1. Context

K1 currently executes tool calls sequentially within the Tool Runner component (Layer 3), with individual calls processed one-at-a-time. This sequential execution pattern creates latency bottlenecks:

**Current State Issues**:

- Tool calls execute serially (1→2→3 sequence)
- Each tool call adds full latency: Tool 1 (100ms) + Tool 2 (100ms) + Tool 3 (100ms) = 300ms total
- No parallelization for independent tools
- Client sees complete latency before any result
- No incremental result streaming to user
- Backpressure from slow clients blocks entire batch

**Performance Analysis**:

- Current latency (3 sequential tools): ~300ms
- Optimal latency (3 parallel tools): ~100ms (33% of sequential)
- P95 tool latency: 300-500ms (varies by tool)
- Missing opportunity: **66% latency reduction possible**

**User Experience Impact**:

- Sequential execution feels slow (300ms for 3-tool turn)
- No early feedback (user waits for all tools to complete)
- Streaming not yet integrated with tool execution

**Research Foundation**:

- Batch processing patterns (Liu et al., ASPLOS 2020 - "Ansor")
- Parallel task execution with DAGs (Zaharia et al., NSDI 2012 - "Spark")
- Server-Sent Events streaming (W3C SSE specification)
- Backpressure in reactive systems (Kumazaki et al., 2015)

**Issue Mapping**:

- Issue 4.1.1: Tool Call Batch Collection (50ms window, 10 calls/batch, priority)
- Issue 4.1.2: Parallel Tool Executor (asyncio.gather, DAG, error isolation)
- Issue 4.1.3: Streaming Result Handler (SSE, delta compression, backpressure)

---

## 2. Decision

Implement a **three-phase Tool Call Batching Pipeline** combining:

### 2.1 Phase 1: Tool Call Batch Collection (Issue 4.1.1)

**Batch Accumulator Pattern**:

```python
from dataclasses import dataclass, field
from enum import Enum
from typing import Dict, List, Optional, Callable
import asyncio
import time
from collections import deque

class ToolCallPriority(Enum):
    """Priority levels for tool call batching"""
    LOW = 0      # Can wait full 50ms window
    NORMAL = 1   # Can wait up to 30ms
    URGENT = 2   # Bypass wait, execute immediately

@dataclass
class ToolCall:
    """Single tool invocation request"""
    tool_id: str                  # Unique tool identifier
    tool_name: str                # Human-readable name (e.g., "calculator")
    input_args: Dict              # Arguments for tool
    trace_id: str                 # Correlation ID for logging
    priority: ToolCallPriority = ToolCallPriority.NORMAL
    timestamp_ms: int = field(default_factory=lambda: int(time.time() * 1000))
    batch_id: Optional[str] = None  # Assigned after batch formation

@dataclass
class ToolCallBatch:
    """Batch of tool calls for parallel execution"""
    batch_id: str
    tool_calls: List[ToolCall]
    created_time_ms: int
    scheduled_time_ms: Optional[int] = None

    def has_urgent(self) -> bool:
        """Check if batch contains urgent calls"""
        return any(tc.priority == ToolCallPriority.URGENT for tc in self.tool_calls)

    def size(self) -> int:
        return len(self.tool_calls)

class ToolCallBatchCollector:
    """Collect tool calls into batches with time/size constraints"""

    def __init__(self,
                 batch_window_ms: int = 50,
                 max_batch_size: int = 10,
                 urgent_priority: ToolCallPriority = ToolCallPriority.URGENT):

        self.batch_window_ms = batch_window_ms
        self.max_batch_size = max_batch_size
        self.urgent_priority = urgent_priority

        # Queue of tool calls waiting for batching
        self.pending_calls: deque[ToolCall] = deque()
        self.pending_lock = asyncio.Lock()

        # Active batch accumulation
        self.current_batch: Optional[ToolCallBatch] = None
        self.batch_start_time_ms: Optional[int] = None

        # Callback when batch ready
        self.on_batch_ready: Optional[Callable[[ToolCallBatch], None]] = None

        # Metrics
        self.batches_created = 0
        self.calls_batched = 0
        self.urgent_batches = 0

    async def add_tool_call(self, tool_call: ToolCall) -> str:
        """Add tool call to batching queue, return batch_id"""

        async with self.pending_lock:
            self.pending_calls.append(tool_call)

            # Check if batch should be flushed
            should_flush = False
            flush_reason = None

            if tool_call.priority == self.urgent_priority:
                # Urgent calls bypass batching window
                should_flush = True
                flush_reason = "URGENT_PRIORITY"

            elif len(self.pending_calls) >= self.max_batch_size:
                # Batch is full (10 calls)
                should_flush = True
                flush_reason = "SIZE_LIMIT"

            if should_flush:
                batch = await self._create_and_schedule_batch(flush_reason)
                return batch.batch_id

            # Start batching timer if not already running
            if self.batch_start_time_ms is None:
                self.batch_start_time_ms = int(time.time() * 1000)

            return None  # Batch ID assigned when batch flushes

    async def _check_batch_timeout(self):
        """Background task: flush batch after 50ms timeout"""

        while True:
            await asyncio.sleep(0.01)  # Check every 10ms

            async with self.pending_lock:
                if self.batch_start_time_ms is None:
                    continue  # No pending calls

                age_ms = int(time.time() * 1000) - self.batch_start_time_ms

                if age_ms >= self.batch_window_ms and len(self.pending_calls) > 0:
                    # Batch timeout reached
                    batch = await self._create_and_schedule_batch("TIMEOUT")

    async def _create_and_schedule_batch(self, flush_reason: str) -> ToolCallBatch:
        """Create batch from pending calls and schedule execution"""

        if not self.pending_calls:
            return None

        # Build batch from pending calls
        batch_calls = []
        batch_size = min(len(self.pending_calls), self.max_batch_size)

        for _ in range(batch_size):
            call = self.pending_calls.popleft()
            batch_calls.append(call)

        # Create batch
        batch_id = f"batch-{int(time.time() * 1000)}-{len(batch_calls):02d}"
        batch = ToolCallBatch(
            batch_id=batch_id,
            tool_calls=batch_calls,
            created_time_ms=int(time.time() * 1000)
        )

        # Assign batch_id to all calls
        for call in batch_calls:
            call.batch_id = batch_id

        # Reset timer
        self.batch_start_time_ms = None if len(self.pending_calls) == 0 else int(time.time() * 1000)

        # Update metrics
        self.batches_created += 1
        self.calls_batched += len(batch_calls)
        if batch.has_urgent():
            self.urgent_batches += 1

        # Export metrics
        metrics.tool_batches_created_total.labels(
            flush_reason=flush_reason
        ).inc()
        metrics.tool_calls_batched_total.add(len(batch_calls))

        # Schedule batch execution
        if self.on_batch_ready:
            self.on_batch_ready(batch)

        return batch

    async def flush(self) -> Optional[ToolCallBatch]:
        """Manually flush current batch (used for final call)"""
        async with self.pending_lock:
            if len(self.pending_calls) > 0:
                return await self._create_and_schedule_batch("MANUAL_FLUSH")
            return None

class ToolCallBatchingGate:
    """Entry point for tool calls into batching system"""

    def __init__(self, max_batch_size: int = 10, batch_window_ms: int = 50):
        self.collector = ToolCallBatchCollector(
            batch_window_ms=batch_window_ms,
            max_batch_size=max_batch_size
        )
        self.executor = None  # Set after initialization (see Phase 2)

    async def submit_tool_call(self, tool_name: str, input_args: Dict,
                               trace_id: str,
                               priority: ToolCallPriority = ToolCallPriority.NORMAL):
        """Submit tool call to batch collector"""

        tool_call = ToolCall(
            tool_id=f"{trace_id}-{tool_name}",
            tool_name=tool_name,
            input_args=input_args,
            trace_id=trace_id,
            priority=priority
        )

        batch_id = await self.collector.add_tool_call(tool_call)

        logger.info(
            "tool_call_submitted_to_batch",
            tool_name=tool_name,
            trace_id=trace_id,
            batch_id=batch_id or "pending",
            priority=priority.name
        )

        return tool_call
```

### 2.2 Phase 2: Parallel Tool Executor (Issue 4.1.2)

**Dependency Graph & Parallel Execution**:

```python
from dataclasses import dataclass
from typing import Set, Dict, List
import asyncio

@dataclass
class ToolDependency:
    """Tool call dependency information"""
    tool_id: str
    depends_on_tool_ids: Set[str] = field(default_factory=set)  # Other tool IDs this depends on

    def has_dependencies(self) -> bool:
        return len(self.depends_on_tool_ids) > 0

class DependencyGraph:
    """Build and traverse dependency graph for tool calls"""

    def __init__(self, tool_calls: List[ToolCall]):
        self.tool_calls = tool_calls
        self.tool_map: Dict[str, ToolCall] = {tc.tool_id: tc for tc in tool_calls}
        self.dependencies: Dict[str, ToolDependency] = {}

        # Infer dependencies from input_args (simplified version)
        # Production version would use more sophisticated analysis
        self._infer_dependencies()

    def _infer_dependencies(self):
        """Infer tool dependencies from argument references"""

        # Tool outputs might be referenced in other tool inputs
        # Example: Tool A output -> Tool B input (Tool B depends on A)

        for tool_call in self.tool_calls:
            deps = ToolDependency(tool_id=tool_call.tool_id)

            # Check if inputs reference other tool outputs
            for arg_value in tool_call.input_args.values():
                if isinstance(arg_value, str) and arg_value.startswith("tool:"):
                    # Reference to another tool output
                    referenced_tool_id = arg_value.replace("tool:", "")
                    if referenced_tool_id in self.tool_map:
                        deps.depends_on_tool_ids.add(referenced_tool_id)

            self.dependencies[tool_call.tool_id] = deps

    def get_execution_order(self) -> List[List[str]]:
        """Return tool execution stages (each stage can run in parallel)"""

        executed = set()
        stages = []

        while len(executed) < len(self.tool_calls):
            # Find all tools with no unexecuted dependencies
            ready_tools = []

            for tool_id, dep in self.dependencies.items():
                if tool_id in executed:
                    continue

                unexecuted_deps = dep.depends_on_tool_ids - executed
                if len(unexecuted_deps) == 0:
                    ready_tools.append(tool_id)

            if not ready_tools:
                # Circular dependency or error
                raise ValueError("Circular dependency detected in tool calls")

            stages.append(ready_tools)
            executed.update(ready_tools)

        return stages

@dataclass
class ToolResult:
    """Result from single tool execution"""
    tool_id: str
    tool_name: str
    success: bool
    output: Optional[Dict] = None
    error: Optional[str] = None
    execution_latency_ms: float = 0.0
    trace_id: str = ""

class ParallelToolExecutor:
    """Execute tool calls in parallel respecting dependencies"""

    def __init__(self, tool_runner):
        self.tool_runner = tool_runner  # Layer 3 Tool Runner service
        self.results: Dict[str, ToolResult] = {}
        self.result_lock = asyncio.Lock()

    async def execute_batch(self, batch: ToolCallBatch) -> Dict[str, ToolResult]:
        """Execute all tools in batch, respecting dependencies"""

        # Build dependency graph
        dep_graph = DependencyGraph(batch.tool_calls)
        execution_stages = dep_graph.get_execution_order()

        logger.info(
            "tool_batch_execution_start",
            batch_id=batch.batch_id,
            tool_count=len(batch.tool_calls),
            execution_stages=len(execution_stages)
        )

        # Execute each stage in sequence (tools within stage run in parallel)
        for stage_idx, stage_tool_ids in enumerate(execution_stages):
            logger.info(
                "tool_stage_start",
                batch_id=batch.batch_id,
                stage=stage_idx,
                tool_count=len(stage_tool_ids)
            )

            # Create tasks for all tools in this stage
            tasks = []
            for tool_id in stage_tool_ids:
                tool_call = next(tc for tc in batch.tool_calls if tc.tool_id == tool_id)
                task = self._execute_tool_with_error_isolation(tool_call, batch.batch_id)
                tasks.append(task)

            # Wait for all tasks in stage to complete
            await asyncio.gather(*tasks)

            logger.info(
                "tool_stage_complete",
                batch_id=batch.batch_id,
                stage=stage_idx
            )

        # Return all results
        return self.results

    async def _execute_tool_with_error_isolation(self, tool_call: ToolCall,
                                                  batch_id: str):
        """Execute single tool with error isolation"""

        tool_id = tool_call.tool_id
        start_ms = time.time() * 1000

        try:
            logger.info(
                "tool_execution_start",
                tool_id=tool_id,
                tool_name=tool_call.tool_name,
                batch_id=batch_id,
                trace_id=tool_call.trace_id
            )

            # Call tool runner (MCP sandbox integration)
            output = await self.tool_runner.run_tool(
                tool_name=tool_call.tool_name,
                input_args=tool_call.input_args,
                trace_id=tool_call.trace_id,
                timeout_ms=3000  # 3-second tool timeout
            )

            latency_ms = time.time() * 1000 - start_ms

            result = ToolResult(
                tool_id=tool_id,
                tool_name=tool_call.tool_name,
                success=True,
                output=output,
                execution_latency_ms=latency_ms,
                trace_id=tool_call.trace_id
            )

            logger.info(
                "tool_execution_success",
                tool_id=tool_id,
                latency_ms=latency_ms,
                trace_id=tool_call.trace_id
            )

        except asyncio.TimeoutError:
            latency_ms = time.time() * 1000 - start_ms
            result = ToolResult(
                tool_id=tool_id,
                tool_name=tool_call.tool_name,
                success=False,
                error=f"Tool timeout after {latency_ms:.0f}ms",
                execution_latency_ms=latency_ms,
                trace_id=tool_call.trace_id
            )

            logger.error(
                "tool_execution_timeout",
                tool_id=tool_id,
                latency_ms=latency_ms,
                trace_id=tool_call.trace_id
            )

        except Exception as e:
            latency_ms = time.time() * 1000 - start_ms
            result = ToolResult(
                tool_id=tool_id,
                tool_name=tool_call.tool_name,
                success=False,
                error=str(e),
                execution_latency_ms=latency_ms,
                trace_id=tool_call.trace_id
            )

            logger.error(
                "tool_execution_error",
                tool_id=tool_id,
                error=str(e),
                latency_ms=latency_ms,
                trace_id=tool_call.trace_id
            )

        # Store result with thread safety
        async with self.result_lock:
            self.results[tool_id] = result

            # Export metrics
            metrics.tool_execution_latency_ms.labels(
                tool_name=tool_call.tool_name,
                success=result.success
            ).observe(result.execution_latency_ms)

            if not result.success:
                metrics.tool_execution_errors_total.labels(
                    tool_name=tool_call.tool_name,
                    error_type=type(result.error).__name__
                ).inc()

class ExecutionMetrics:
    """Execution monitoring"""

    tool_execution_latency_ms = Histogram(
        'tool_execution_latency_ms',
        'Per-tool execution latency',
```

### 2.3 Phase 3: Streaming Result Handler (Issue 4.1.3)

**Server-Sent Events (SSE) Result Streaming**:

```python
from aiohttp import web
import json
from typing import AsyncGenerator
import asyncio

class StreamingResultHandler:
    """Stream tool results to client via SSE as they complete"""

    def __init__(self):
        self.streaming_clients = {}  # {session_id: client_writer}

    async def stream_batch_results(self, batch_id: str,
                                   batch: ToolCallBatch,
                                   executor: ParallelToolExecutor
                                   ) -> AsyncGenerator[str, None]:
        """Stream tool results as they complete (no waiting for last tool)"""

        # Start execution in background
        execution_task = asyncio.create_task(executor.execute_batch(batch))

        logger.info(
            "sse_streaming_start",
            batch_id=batch_id,
            tool_count=len(batch.tool_calls)
        )

        # Stream batch start event
        yield self._format_sse_event(
            event_type="batch_start",
            data={
                "batch_id": batch_id,
                "tool_count": len(batch.tool_calls),
                "timestamp_ms": int(time.time() * 1000)
            }
        )

        # Monitor for result completion
        completed_tools = set()
        start_time_ms = time.time() * 1000

        while len(completed_tools) < len(batch.tool_calls):
            await asyncio.sleep(0.01)  # Poll every 10ms

            # Check for newly completed tools
            for tool_id, result in executor.results.items():
                if tool_id not in completed_tools:
                    completed_tools.add(tool_id)

                    # Compress result payload (delta compression)
                    compressed_result = self._compress_result(result)

                    # Stream result event
                    yield self._format_sse_event(
                        event_type="tool_result",
                        data={
                            "batch_id": batch_id,
                            "tool_id": tool_id,
                            "tool_name": result.tool_name,
                            "success": result.success,
                            "output": compressed_result,
                            "error": result.error,
                            "latency_ms": result.execution_latency_ms,
                            "timestamp_ms": int(time.time() * 1000)
                        }
                    )

                    logger.info(
                        "sse_result_streamed",
                        batch_id=batch_id,
                        tool_id=tool_id,
                        success=result.success
                    )

                    # Export metrics
                    metrics.sse_results_streamed_total.inc()

        # Wait for execution task to complete
        await execution_task

        total_latency_ms = time.time() * 1000 - start_time_ms

        # Stream batch complete event
        yield self._format_sse_event(
            event_type="batch_complete",
            data={
                "batch_id": batch_id,
                "total_latency_ms": total_latency_ms,
                "timestamp_ms": int(time.time() * 1000)
            }
        )

        logger.info(
            "sse_streaming_complete",
            batch_id=batch_id,
            total_latency_ms=total_latency_ms
        )

    def _format_sse_event(self, event_type: str, data: Dict) -> str:
        """Format data as Server-Sent Event"""

        json_data = json.dumps(data)
        return f"event: {event_type}\ndata: {json_data}\n\n"

    def _compress_result(self, result: ToolResult) -> Dict:
        """Delta compress result payload"""

        # Delta compression: only include non-null fields
        compressed = {
            "tool_id": result.tool_id,
            "success": result.success
        }

        if result.success and result.output:
            # Compress output (simplified version)
            # Production: use zstd compression from ADR 0076
            compressed["output"] = result.output

        if not result.success and result.error:
            compressed["error"] = result.error

        return compressed

    async def handle_sse_request(self, request: web.Request) -> web.StreamResponse:
        """HTTP endpoint for SSE streaming"""

        batch_id = request.match_info['batch_id']

        # Create SSE response
        response = web.StreamResponse()
        response.content_type = 'text/event-stream'
        response.headers['Cache-Control'] = 'no-cache'
        response.headers['X-Accel-Buffering'] = 'no'

        try:
            # Get batch and executor
            batch = self._get_batch(batch_id)
            executor = self._get_executor(batch_id)

            # Stream results
            async for event in self.stream_batch_results(batch_id, batch, executor):
                await response.write(event.encode('utf-8'))
                await response.write_eof()

        except BackpressureError as e:
            # Client slow; apply backpressure
            logger.warning(
                "sse_backpressure_applied",
                batch_id=batch_id,
                reason=str(e)
            )
            metrics.sse_backpressure_events.inc()

        return response

class BackpressureHandler:
    """Handle backpressure from slow clients"""

    def __init__(self, max_queue_size: int = 100):
        self.max_queue_size = max_queue_size
        self.result_queues = {}  # {batch_id: asyncio.Queue}

    async def write_result(self, batch_id: str, result: ToolResult):
        """Write result to client queue with backpressure"""

        if batch_id not in self.result_queues:
            self.result_queues[batch_id] = asyncio.Queue(maxsize=self.max_queue_size)

        queue = self.result_queues[batch_id]

        try:
            # Try to write (will block if queue full)
            queue.put_nowait(result)
        except asyncio.QueueFull:
            # Queue full; apply backpressure
            logger.warning(
                "result_queue_full_backpressure",
                batch_id=batch_id,
                queue_size=queue.qsize()
            )
            metrics.backpressure_applied_total.inc()

            # Wait for queue to drain before retrying
            await queue.put(result)

    async def read_result(self, batch_id: str) -> ToolResult:
        """Read result from queue (blocks if empty)"""

        if batch_id not in self.result_queues:
            self.result_queues[batch_id] = asyncio.Queue(maxsize=self.max_queue_size)

        queue = self.result_queues[batch_id]
        return await queue.get()

# Metrics
sse_results_streamed_total = Counter(
    'sse_results_streamed_total',
    'Total tool results streamed via SSE'
)
```

**Result Ordering & Guarantee**:

```python
class ResultOrdering:
    """Ensure results preserve order despite parallel execution"""

    def __init__(self, batch: ToolCallBatch):
        self.batch = batch
        self.tool_order = {tc.tool_id: idx for idx, tc in enumerate(batch.tool_calls)}
        self.results_received = set()

    async def stream_in_order(self, executor: ParallelToolExecutor
                              ) -> AsyncGenerator[ToolResult, None]:
        """Stream results in original order"""

        next_index = 0
        results_buffer = {}  # {tool_id: result}

        while next_index < len(self.batch.tool_calls):
            # Get next tool in original order
            next_tool_id = list(self.tool_order.keys())[next_index]

            # Wait for this tool's result
            while next_tool_id not in executor.results:
                await asyncio.sleep(0.01)

            result = executor.results[next_tool_id]
            yield result
            next_index += 1
```

## 3. Consequences

### 3.1 Benefits

✅ **Latency Reduction**

- Sequential 3-tool execution: 300ms → Parallel: 100ms (66% reduction)
- P95 tool latency: 300-500ms → <3000ms budget
- Early result streaming: Client sees partial results as they complete

✅ **Throughput Improvement**

- Batching combines up to 10 independent tool calls
- Parallel execution eliminates serialization overhead
- Per-tool isolation prevents cascading failures

✅ **Better UX**

- Streaming results (incremental feedback)
- No waiting for slowest tool
- Backpressure handling prevents memory buildup

✅ **Resource Efficiency**

- Parallelization better uses multi-core systems
- Batch collection reduces syscall overhead
- Delta compression reduces bandwidth

### 3.2 Costs & Tradeoffs

⚠️ **Complexity Increase**

- Dependency graph construction (simple DAG solver)
- Parallel execution orchestration (asyncio coordination)
- Error isolation requires careful resource management
- Backpressure handling adds state tracking

⚠️ **Memory Overhead**

- Batch queue stores up to 10 pending calls
- Result buffers for incomplete batches
- SSE event queue per client

⚠️ **Integration Dependencies**

- Requires Layer 3 Tool Runner support for async execution
- Depends on MCP sandbox (ADR 0033a) for tool isolation
- Requires SSE infrastructure (see ADR 0042)

### 3.3 Backward Compatibility

**No Breaking Changes**:

- Sequential execution still supported (batch size = 1)
- Tool API unchanged (same input/output format)
- Clients can ignore streaming (treat as single response)
