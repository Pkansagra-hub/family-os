## Context

### Problem Statement

AI systems must **learn from user interactions** to improve over time:
- **Personalization:** Adapt to user preferences (verbosity, tone, topics)
- **Error correction:** Learn from mistakes (intent misclassification, bad suggestions)
- **Quality improvement:** Optimize parameters (temperature, top-k, confidence thresholds)
- **Safety enhancement:** Detect and prevent repeated failures

**Challenges:**
1. **State persistence:** Where to store learned preferences?
2. **Safety boundaries:** How to prevent unsafe adaptations?
3. **Drift detection:** When has system learned something wrong?
4. **Audit trail:** How to rollback bad learning?
5. **K0/K1 boundary:** Who owns persistence?

---

## Decision

### 🚨 CRITICAL K0/K1 BOUNDARY RULE 🚨

**K1 Learning Loop: ADVISORY ONLY**
- ✅ Collect feedback signals (explicit, implicit, behavioral)
- ✅ Analyze patterns and suggest adjustments
- ✅ Emit advisory recommendations
- ✅ Monitor for drift and emit rollback advisories
- ❌ **NEVER persist learned state directly**
- ❌ **NEVER write to SessionState**
- ❌ **NEVER modify K0 databases**

**K0 P06 FeedbackIntegration: AUTHORITATIVE PERSISTENCE**
- ✅ Receive advisory signals from K1
- ✅ Validate against safety policies
- ✅ Persist learned preferences with receipts
- ✅ Execute rollback commands
- ✅ Maintain audit trail via WAL
- ❌ K0 does NOT decide what to learn (K1's job)

**Flow:**
```
K1 Learning Loop → Advisory Signal → K0 P06 Gateway → Validation → Persistence → Receipt → K1
```

### 1. Learning Loop Architecture

**High-Level Pipeline:**
```python
class K1LearningLoop:
    """
    K1 Learning Loop - ADVISORY ONLY
    Collects feedback, suggests adaptations, monitors drift
    """
    def __init__(self):
        self.signal_collector = FeedbackSignalCollector()
        self.drift_monitor = DriftMonitor()
        self.advisory_emitter = AdvisoryEmitter()
        self.k0_gateway = K0P06Gateway()  # Communication with K0 P06

    async def process_feedback(self,
                               feedback: Feedback,
                               session: Session) -> Advisory:
        """Process feedback and emit advisory"""

        # Step 1: Collect and classify signal (ADR-0059a)
        signal = await self.signal_collector.collect(feedback, session)

        # Step 2: Analyze patterns
        recommendation = await self.analyze_for_adaptation(signal, session)

        # Step 3: Check for drift (ADR-0059b)
        drift_status = await self.drift_monitor.check(recommendation, session)

        if drift_status.is_anomalous:
            # Emit rollback advisory
            advisory = Advisory(
                type=AdvisoryType.ROLLBACK,
                reason=drift_status.reason,
                session_id=session.id
            )
        else:
            # Emit adaptation advisory
            advisory = Advisory(
                type=AdvisoryType.ADAPT,
                recommendation=recommendation,
                confidence=recommendation.confidence
            )

        # Step 4: Send to K0 P06 for validation + persistence
        receipt = await self.k0_gateway.submit_advisory(advisory)

        logger.info(
            "learning_advisory_emitted",
            type=advisory.type,
            receipt_id=receipt.id
        )

        return advisory
```

### 2. K0 P06 Gateway (Boundary Interface)

**Communication Protocol:**
```python
class K0P06Gateway:
    """
    Gateway for K1 → K0 P06 communication
    K1 NEVER persists directly, always goes through this gateway
    """
    def __init__(self):
        self.p06_client = P06Client(port=P06_PORT)  # K0 P06 FeedbackIntegration

    async def submit_advisory(self, advisory: Advisory) -> Receipt:
        """Submit advisory to K0 P06 for validation + persistence"""

        # Serialize advisory
        request = P06AdvisoryRequest(
            advisory_id=advisory.id,
            type=advisory.type,
            payload=advisory.to_dict(),
            source="K1_LEARNING_LOOP",
            timestamp=time.time()
        )

        # Send to K0 P06 (over port boundary)
        try:
            response = await self.p06_client.submit_advisory(request)

            if response.status == "accepted":
                logger.info(
                    "k0_p06_accepted_advisory",
                    advisory_id=advisory.id,
                    receipt_id=response.receipt.id
                )
                return response.receipt

            elif response.status == "rejected":
                logger.warning(
                    "k0_p06_rejected_advisory",
                    advisory_id=advisory.id,
                    reason=response.rejection_reason
                )
                raise AdvisoryRejectedError(response.rejection_reason)

        except Exception as e:
            logger.error(
                "k0_p06_gateway_error",
                advisory_id=advisory.id,
                error=str(e)
            )
            raise
```

### 5. Drift Detection (ADR-0059b)

**Statistical Monitoring:**
```python
class DriftMonitor:
    """Detect when learning has gone wrong"""

    DRIFT_THRESHOLDS = {
        "max_parameter_change_per_day": 0.2,  # 20% max daily drift
        "max_negative_feedback_ratio": 0.3,   # 30% negative → rollback
        "anomaly_z_score": 3.0,               # 3 standard deviations
    }

    async def check(self,
                   recommendation: AdaptationRecommendation,
                   session: Session) -> DriftStatus:
        """Check if recommendation is anomalous"""

        # Get historical values
        history = await self.get_parameter_history(
            parameter=recommendation.parameter,
            session_id=session.id,
            lookback_days=7
        )

        # Check rate of change
        if self.is_changing_too_fast(recommendation, history):
            return DriftStatus(
                is_anomalous=True,
                reason="parameter_changing_too_fast"
            )

        # Check if negative feedback is high
        recent_feedback = await self.get_recent_feedback(session.id, hours=24)
        negative_ratio = self.calculate_negative_ratio(recent_feedback)

        if negative_ratio > self.DRIFT_THRESHOLDS["max_negative_feedback_ratio"]:
            return DriftStatus(
                is_anomalous=True,
                reason="high_negative_feedback"
            )

        # Check statistical anomaly
        z_score = self.calculate_z_score(recommendation.new_value, history)

        if abs(z_score) > self.DRIFT_THRESHOLDS["anomaly_z_score"]:
            return DriftStatus(
                is_anomalous=True,
                reason="statistical_anomaly"
            )

        return DriftStatus(is_anomalous=False)
```

### 6. Rollback Mechanism (ADR-0059d)

**User-Initiated Rollback:**
```python
class RollbackHandler:
    """Handle rollback of learned preferences"""

    async def rollback_to_point(self,
                               session_id: str,
                               timestamp: float) -> RollbackResult:
        """Rollback learned preferences to specific time"""

        # K1 emits rollback advisory
        advisory = Advisory(
            type=AdvisoryType.ROLLBACK,
            session_id=session_id,
            target_timestamp=timestamp,
            reason="user_initiated"
        )

        # K0 P06 executes rollback (via WAL)
        receipt = await self.k0_gateway.submit_advisory(advisory)

        logger.info(
            "rollback_initiated",
            session_id=session_id,
            target_timestamp=timestamp,
            receipt_id=receipt.id
        )

        return RollbackResult(
            success=True,
            receipt=receipt
        )
```

## Consequences

### Positive

✅ **Clear Boundary:** K1 advisory, K0 authoritative
✅ **Safe Learning:** Drift detection prevents bad adaptations
✅ **Auditable:** Full rollback capability via K0 WAL
✅ **Personalization:** Adapts to user preferences over time
✅ **Multi-Signal:** Combines explicit, implicit, behavioral feedback

### Negative

⚠️ **Complexity:** Two-kernel coordination overhead
⚠️ **Latency:** Advisory → validation → persistence adds 50-100ms
⚠️ **False Positives:** Drift detection may block valid adaptations

### Trade-offs

**K1 Advisory vs. K1 Authoritative:**
- **Chosen:** K1 advisory, K0 authoritative
- **Alternative:** Let K1 persist directly (faster, but violates boundary)
- **Rationale:** Safety and auditability require K0 control

**Learning Rate:**
- **Aggressive (high rate):** Fast personalization, higher drift risk
- **Conservative (low rate):** Slow adaptation, safer
- **Decision:** Conservative by default, user can tune
