## Context

### Problem Statement

Voice pipelines have **unique backpressure characteristics** compared to text:

**ASR Challenges:**
- Real-time audio frames (50 FPS @ 20ms frames)
- Cannot buffer indefinitely (causes drift)
- Dropped frames lose context

**TTS Challenges:**
- Streaming synthesis must keep pace with playback
- Quality degradation more noticeable than text
- Interruption (barge-in) requires cleanup

**Current State:**
- ADR-0039 defines general backpressure cascade (80/90/95% watermarks)
- Voice-specific strategies undefined
- Barge-in recovery not specified

---

## Decision

We implement **3-tier voice backpressure** with pipeline-specific strategies:

### 1. Backpressure Architecture

**Voice Pipeline Stages:**
```
Audio In (50 FPS) → ASR → Intent → Tools → TTS → Audio Out (25 CPS)
   │                  │                        │
   └─ Drop @ 80%     └─────────────────────┘
      Downsample @ 90%                         └─ Degrade @ 90%
                                                  Interrupt (barge-in)
```

**Watermark Thresholds:**
```python
VOICE_BACKPRESSURE_THRESHOLDS = {
    # ASR Ingress
    "asr_frame_drop_threshold": 0.80,      # Drop frames at 80% capacity
    "asr_downsample_threshold": 0.90,      # Downsample at 90%

    # TTS Synthesis
    "tts_degradation_threshold": 0.90,     # Reduce quality at 90%
    "tts_skip_prosody_threshold": 0.95,    # Skip prosody at 95%

    # Barge-in
    "barge_in_latency_ms": 120,            # Interrupt TTS <120ms
}
```

### 2. ASR Frame Management

**Strategy: Selective Frame Dropping**
```python
class ASRBackpressure:
    def __init__(self):
        self.frame_queue = asyncio.Queue(maxsize=10)  # 200ms buffer
        self.current_load = 0.0

    async def handle_frame(self, frame: AudioFrame) -> Optional[AudioFrame]:
        """Apply backpressure to ASR frames"""
        self.current_load = self.frame_queue.qsize() / self.frame_queue.maxsize

        if self.current_load >= 0.90:
            # 90%+ → Downsample (16kHz → 8kHz)
            downsampled = self.downsample_frame(frame)
            logger.warning("asr_frame_downsampled", load=self.current_load)
            return downsampled

        elif self.current_load >= 0.80:
            # 80-90% → Drop every other frame
            if frame.sequence_number % 2 == 0:
                logger.info("asr_frame_dropped", load=self.current_load)
                return None  # Drop
            return frame

        else:
            # <80% → Normal processing
            return frame
```

### 3. TTS Quality Degradation

**Degradation Ladder:**
```python
class TTSBackpressure:
    QUALITY_LEVELS = [
        # Level 0: Full quality
        {"bitrate": 32, "prosody": True, "sample_rate": 24000},
        # Level 1: Reduced bitrate
        {"bitrate": 24, "prosody": True, "sample_rate": 24000},
        # Level 2: Lower sample rate
        {"bitrate": 24, "prosody": True, "sample_rate": 16000},
        # Level 3: No prosody
        {"bitrate": 24, "prosody": False, "sample_rate": 16000},
        # Level 4: Minimum quality
        {"bitrate": 16, "prosody": False, "sample_rate": 16000},
    ]

    def select_quality_level(self, load: float) -> dict:
        """Select TTS quality based on load"""
        if load < 0.80:
            return self.QUALITY_LEVELS[0]  # Full quality
        elif load < 0.85:
            return self.QUALITY_LEVELS[1]  # Reduced bitrate
        elif load < 0.90:
            return self.QUALITY_LEVELS[2]  # Lower sample rate
        elif load < 0.95:
            return self.QUALITY_LEVELS[3]  # No prosody
        else:
            return self.QUALITY_LEVELS[4]  # Minimum
```

### 4. Barge-in Protocol

**Interrupt + Recovery:**
```python
class BargeInHandler:
    async def on_user_interruption(self, session_id: str, new_message: str):
        """Handle user interrupting agent response"""
        # Step 1: Stop TTS immediately (<120ms)
        await self.tts_pipeline.stop_synthesis(session_id)

        # Step 2: Cancel ongoing tool executions
        await self.tool_runner.cancel_session(session_id)

        # Step 3: Preserve partial context
        partial_response = await self.get_partial_response(session_id)
        await self.session_state.save_interrupted_context(
            session_id,
            partial_response
        )

        # Step 4: Process new user message
        await self.process_user_message(session_id, new_message)

        logger.info(
            "barge_in_handled",
            session_id=session_id,
            latency_ms=self.measure_latency()
        )
```

### 5. Integration with ADR-0039

**3-Tier Cascade:**
```python
def calculate_pipeline_load() -> float:
    """Calculate combined voice pipeline load"""
    asr_load = asr_pipeline.get_load()
    tts_load = tts_pipeline.get_load()

    # Weighted average (ASR heavier due to frame rate)
    return (asr_load * 0.6) + (tts_load * 0.4)

async def apply_backpressure(load: float):
    """Apply backpressure based on load"""
    if load >= 0.95:
        # Critical: Reject new sessions
        raise BackpressureError("Voice pipeline at capacity")

    elif load >= 0.90:
        # High: Degrade both ASR and TTS
        await asr_pipeline.apply_backpressure(load)
        await tts_pipeline.apply_backpressure(load)

    elif load >= 0.80:
        # Medium: Drop ASR frames only
        await asr_pipeline.apply_backpressure(load)
```

## Consequences

### Positive

✅ **Graceful Degradation**: Voice quality reduces smoothly under load
✅ **Fast Barge-in**: <120ms interruption latency
✅ **Context Preservation**: No data loss on interruption
✅ **Adaptive**: Responds to real-time load conditions

### Negative

⚠️ **Quality Loss**: Degraded voice quality noticeable to users
⚠️ **ASR Accuracy**: Dropped frames may reduce transcription quality
⚠️ **Complexity**: Multiple degradation strategies to coordinate

## Validation

**Load Tests:**
```python
@test("voice pipeline handles 50 sessions")
async def test_voice_load():
    pipeline = VoicePipeline()

    # Simulate 50 concurrent sessions
    sessions = [
        pipeline.start_session(f"session_{i}")
        for i in range(50)
    ]

    await asyncio.gather(*sessions)

    # Verify backpressure applied
    assert pipeline.frames_dropped > 0
    assert pipeline.tts_quality_degraded > 0
    assert pipeline.sessions_rejected == 0  # No rejections

@test("barge-in under 120ms")
async def test_barge_in_latency():
    handler = BargeInHandler()

    start = time.time()
    await handler.on_user_interruption("s1", "Stop")
    latency_ms = (time.time() - start) * 1000

    assert latency_ms < 120  # P95 target
```
