## Context

The POC relies on consistent external tool semantics via the Tool Registry + Mock MCP. Finance-focused queries previously mapped to a generic UserKG passthrough (get_financial_context) with ad-hoc normalization in FinanceAgent. To tighten consistency and enable schema-stable testing, we introduce a dedicated tool: query_k0_finance.

## Decision

- Add query_k0_finance to the Tool Registry (class and JSON config)
  - Parameters: user_id (required), query (required), month (optional)
  - Returns: transaction_count, current_month_total, category_spending[], recent_transactions[], budget_utilization
- Extend Mock MCP mock_tool_responses with deterministic generator for query_k0_finance (1200/1500 → 0.80)
- Update FinanceAgent to call query_k0_finance directly for episodic transactions instead of inferring from get_financial_context
- Add an integration test that patches ToolCallHandler globally and validates Concierge → Finance path invokes ToolCallHandler for finance tools including query_k0_finance

## Consequences

Positive:

- Stable, explicit schema for finance episodic queries
- Simpler logic in FinanceAgent (less normalization, clearer contract)
- Testability improved (mock generator + routing test)

Negative/Risks:

- Slight duplication with get_financial_context (kept for budget/goals)
- Requires keeping registry JSON and class registry in sync

## Alternatives Considered

- Continue deriving transactions from get_financial_context only (rejected: conflates concerns, brittle mapping)
- Add no new tool and patch tests to internal agent methods (rejected: hides contract, reduces clarity)

## Implementation Notes

- Tool added in l5_infrastructure/registries/tool_registry.py and config/tool_registry.json
- Mock response generator added in mock_services/mock_tool_responses.py
- FinanceAgent updated to call query_k0_finance
- New integration test: tests/integration/test_concierge_to_finance_tool_routing.py

## Validation

- Focused pytest runs for specialist routing and concierge→finance routing pass locally
- Mock response coverage extended to include query_k0_finance
